# Ethernet

<img src="/img/ethernet-cable.png" width="25%" />

Ethernet is a technology used for connecting devices in a local network. An ethernet cable is used to physically connect devices like computers, routers, and switches to enable communication and data transfer between them.

## What we use it for?
In our case, we use it to connect devices like the [X18 Wireless Board(Digital Mixer)](/docs/Audio/X18%20Wireless%20Board) to a router so that they can communicate with other devices on the network, such as an iPad used for controlling the mixer.

## Where it is?
An ethernet cable can be found in the router box.
